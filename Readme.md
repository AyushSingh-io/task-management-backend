# Task Management Backend

A RESTful backend API for a task management application built with Node.js, Express, and MongoDB.

## Tech Stack

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT Authentication
- Bcrypt
- Cloudinary
- Multer

## Features

- User Authentication
- Project Management
- Task Management
- Comments
- Project Members & Roles

## Project Structure

```
src/
├── controllers/
├── models/
├── routes/
├── middlewares/
├── database/
├── utils/
├── app.js
└── index.js
```

## Getting Started

### Clone the repository

```bash
git clone <repository-url>
```

### Install dependencies

```bash
npm install
```

### Create a `.env` file

```env
PORT=8000
MONGODB_URI=your_mongodb_connection_string
CORS_ORIGIN=*
ACCESS_TOKEN_SECRET=your_secret
REFRESH_TOKEN_SECRET=your_secret
```

### Run the server

```bash
npm run dev
```
